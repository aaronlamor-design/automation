# IMPORTANT DO NOT SKIP ON READING THIS FILE

This is an automation script for [FireFaucet.win](https://firefaucet.win/ref/1568183?s=github)

### To use you'll need to update the config.json. I put in some defaults for chrome, profile, and port.  You'll have to sign up to [FireFaucet.win](https://firefaucet.win/ref/1568183?s=github) before using. add your username and password to the empty "" in the config.json

If you change anything in the config.json file make sure to follow the already existing format else app.exe won't work. for example, "chrome": "C:\\\\Program Files\\\\Google\\\\Chrome\\\\Application\\\\chrome.exe". make sure to use \\\\. This is the same for profile. I DO NOT recommend using the default chrome profile. This script will create a chrome profile directory where ever you specify. The recommended port is 9222, though you can change this number as long as an other application or program is not using it.
