# IMPORTANT DO NOT SKIP ON READING THIS FILE

This is an automation script for [FireFaucet.win](https://firefaucet.win/ref/1568183?s=github)

## To use you'll need to create a config.json in the same folder as your app.exe. Copy and paste the following into the config.json file:

{  
&emsp;&emsp;"chrome": "",  
&emsp;&emsp;"profile": "",  
&emsp;&emsp;"port": "",  
&emsp;&emsp;"username": "",  
&emsp;&emsp;"password": ""  
}

For chrome and profile you need to point to where the paths are. for example "chrome": "C:\\\\Program Files\\\\Google\\\\Chrome\\\\Application\\\\chrome.exe". make sure to use \\\\. I recommend not using the default chrome profile. This script will create a chrome profile directory where ever you specify. recommended port is 9222.

Sign up to [FireFaucet.win](https://firefaucet.win/ref/1568183?s=github) before using.
