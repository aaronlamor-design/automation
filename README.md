this is an automation script for the website [Fire Faucet](https://firefaucet.win/ref/1568183?s=github)

to use edit the config file to enter chrome location, chrome profile (I recommend not using the default. this script will create a new profile in specified location), port number, and fire faucet account username and password.

for paths in config make sure to use \\. for example "chrome": "C:\\Program Files\\Google\\Chrome\\Application\\chrome.exe". recommended port is 9222.
